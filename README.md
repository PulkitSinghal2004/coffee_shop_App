# Coffee Shop App (React Native & Zustand)
This project is a fully functional mobile coffee shop application built using React Native for the frontend and Zustand for state management.  It allows users to browse a selection of coffees and coffee beans, search for specific items, view detailed information, favorite items, add them to a cart, and simulate placing an order.

## Features
   * **Browse Coffees & Beans:** Explore a diverse catalog of coffee beans and pre-made coffee beverages.
   * **Search Functionality:** Quickly find your favorite coffees or beans using the integrated search feature.
   * **Detailed View:** Access comprehensive information about each item, including special ingredients, roast level, ratings, and descriptions.
   * **Favorites:** Mark your preferred items as favorites for easy access and future reference.
   * **Shopping Cart:** Add desired items to your cart and manage your selections.
   * **Order Placement (Simulated):**  Simulate the process of placing an order.  (Note: This app does not integrate with a real payment gateway or backend for actual order 
    fulfillment.)
   * **State Management with Zustand:**  Leverages Zustand for efficient and scalable state management, ensuring a smooth and responsive user experience.
   * **React Native:** Built using React Native, enabling cross-platform compatibility for iOS and Android.

## Installation

1. **Clone the repository:**
      git clone
   
3. **Navigate to the project directory:**
       cd CoffeeShopApp
   
5. **Install dependencies:**
      npm install  # or yarn install
   
7.  **Run the app:**
       npx react-native run-android  # For Android
        npx react-native run-ios    # For iOS
